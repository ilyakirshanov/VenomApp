Это мой проект, в котором я написал уязвимое веб-приложение, а потом исправлял уязвимости, записывая изменения на Github, используя CI пайплайн с настроенным SAST & DAST.

Это веб-приложение я написал, вдохновляясь лабораторными на Portswigger, пытаясь реализовать похожую логику, но при этом получить опыт разработки веб-приложений. Пользовательский интерфейс предоставляет возможность просматривать посты, которые сделал администратор. Доступен вход на сайт, пользователь может зарегистрироваться и войти, в таком случае ему предоставляется функционал смены пароля и эл. почты. У администратора также есть возможность создания постов с изображениями и подписью к ним и возможность удаления аккаунтов пользователей.

Приложение содержит бэкенд на Python(Flask, SQLite3), использует БД SQL, и фронтенд на HTML, CSS и JS. Фронтенд был изначально написан ИИ с предусмотренной уязвимостью XSS. 

На github реализовано три ветки: vulnerable - исходное уязвимое приложение, fixes - исправления уязвимостей и main - приложение с исправленными уязвимостями. 

В пайплайне реализован SAST (semgrep) на каждое изменение и DAST (ZAP / Burp Suite) на изначальное приложение vulnerable и исправленное main. 

В проектировании изначального приложения и дальнейшем исправлении уязвимостей я опирался на Threat Modelling по методу STRIDE + DREAD и на некоторые практики безопасной разработки, описанные в ГОСТ Р 56939-2024 (учитывая учебный характер проекта, методология модели угроз и реализация практик из ГОСТ Р 56939-2024 осуществлена выборочно).
